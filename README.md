# OpenWeather API Client

Консольное приложение для получения прогноза погоды через OpenWeather API с поддержкой кэширования и автоматических повторов при ошибках.

## Возможности

- 🌍 Поиск погоды по городам по всему миру (на русском языке)
- 🔄 Автоматические повторы при ошибках 429 и временных сетевых сбоях
- 💾 Кэширование последнего успешного запроса
- 🎨 Цветной вывод в консоли
- 🧪 Тестовый модуль для проверки HTTP запросов (GET/POST)

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd OpenWeather
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:
```bash
# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Создайте файл `.env` и добавьте ваш API ключ:
```
API_KEY=ваш_ключ_openweather
```

Получить API ключ можно на [OpenWeatherMap](https://openweathermap.org/api)

## Использование

### Программа прогноза погоды

```bash
python weather_app.py
```

Введите название города и страны на русском языке. Программа выведет текущую температуру и описание погоды.

**Пример:**
```
Введите название города (на русском языке): Москва
Введите название страны (на русском языке): Россия

Погода в Москва: 12.4°C, пасмурно
```

### Тестовый модуль для HTTP запросов

```bash
python main.py
```

Интерактивный инструмент для тестирования GET и POST запросов к любым API.

## Структура проекта

- `weather_app.py` - Основное приложение для получения погоды
- `http_client.py` - Модуль для HTTP запросов с базовой проверкой статуса
- `main.py` - Тестовый модуль для проверки API запросов
- `requirements.txt` - Зависимости проекта
- `weather_cache.json` - Кэш последнего успешного запроса (создается автоматически)

## Особенности реализации

- **Ретраи с экспоненциальной паузой**: При ошибках 429 или временных сетевых сбоях выполняется до 3 попыток с паузами 1с, 2с, 4с
- **Кэширование**: Последний успешный ответ сохраняется в `weather_cache.json` с метаданными (город, страна, время запроса)
- **Обработка ошибок**: Понятные сообщения об ошибках без трейсбеков
- **Модульная архитектура**: Разделение на логические модули для удобства поддержки
