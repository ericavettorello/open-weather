# OpenWeather API Client

Telegram-бот для получения прогноза погоды через OpenWeather API с поддержкой кэширования, автоматических повторов при ошибках и многоязычности.

## Возможности

- 🌍 Поиск погоды по городам по всему миру
- 🔄 Автоматические повторы при ошибках 429 и временных сетевых сбоях
- 💾 Кэширование запросов для оптимизации
- 🌐 Многоязычный интерфейс (Русский / English)
- 📱 Удобный Telegram-бот интерфейс
- 🧪 Тестовый модуль для проверки HTTP запросов (GET/POST) - опционально

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ericavettorello/open-weather.git
cd open-weather
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:
```bash
# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Создайте файл `.env` и добавьте ваши ключи:
```
API_KEY=ваш_ключ_openweather
TELEGRAM_BOT_TOKEN=ваш_токен_telegram_бота
```

Получить API ключ можно на [OpenWeatherMap](https://openweathermap.org/api)  
Получить токен Telegram-бота можно у [@BotFather](https://t.me/BotFather) в Telegram

## Структура проекта

### Основные модули

- `bot.py` - Telegram-бот для получения прогноза погоды (основное приложение)
- `main.py` - Тестовый модуль для проверки API запросов (опционально)

### Модули API и данных

- `config.py` - Конфигурация проекта (URLs, настройки, API ключи)
- `api_client.py` - HTTP клиент с ретраями и обработкой ошибок
- `geocoding.py` - Модуль для работы с геокодированием (поиск координат городов)
- `weather_api.py` - Модуль для работы с API погоды (текущая погода, прогноз, UV индекс)
- `air_pollution.py` - Модуль для работы с данными о загрязнении воздуха
- `cache.py` - Модуль для работы с кэшированием данных
- `storage.py` - Модуль для работы с данными пользователей
- `http_client.py` - Базовый модуль для HTTP запросов (используется в main.py)
- `logger.py` - Модуль настройки системы логирования
- `i18n.py` - Модуль для работы с многоязычностью (i18n)

### Файлы и директории

- `requirements.txt` - Зависимости проекта
- `weather_cache.json` - Кэш последнего успешного запроса (создается автоматически)
- `User_Data.json` - Данные пользователей бота (создается автоматически)
- `.cache/` - Директория с файлами кэша (создается автоматически)
- `logs/` - Директория с лог-файлами (создается автоматически)

## Особенности реализации

- **Ретраи с экспоненциальной паузой**: При ошибках 429 или временных сетевых сбоях выполняется до 3 попыток с паузами 1с, 2с, 4с
- **Кэширование**: Запросы кэшируются для оптимизации и уменьшения нагрузки на API
- **Обработка ошибок**: Понятные сообщения об ошибках без трейсбеков
- **Модульная архитектура**: Разделение на логические модули для удобства поддержки
- **Система логирования**: Полноценная система логирования с записью в файлы и выводом в консоль
- **Многоязычность**: Поддержка русского и английского языков с автоматическим выбором языка для API запросов

## Логирование

Проект использует встроенную систему логирования Python (`logging`). Все логи сохраняются в директории `logs/` с автоматической ротацией файлов.

### Настройка уровня логирования

Уровень логирования можно настроить через переменную окружения `LOG_LEVEL` в файле `.env`:

```
LOG_LEVEL=DEBUG  # или INFO, WARNING, ERROR, CRITICAL
```

По умолчанию используется уровень `INFO`.

### Уровни логирования

- **DEBUG** - Детальная информация для отладки
- **INFO** - Общая информация о работе приложения
- **WARNING** - Предупреждения о потенциальных проблемах
- **ERROR** - Ошибки, которые не прерывают работу приложения
- **CRITICAL** - Критические ошибки, которые могут привести к остановке приложения

### Лог-файлы

Логи сохраняются в файлы формата `openweather_YYYYMMDD.log` в директории `logs/`. Файлы автоматически ротируются при достижении размера 10 МБ, сохраняется до 5 резервных копий.

## Многоязычность

Проект поддерживает многоязычный интерфейс в Telegram-боте. При запуске бота пользователь может выбрать язык через меню:

- **Русский (ru)** - интерфейс и данные API на русском языке
- **English (en)** - интерфейс и данные API на английском языке

### Поддерживаемые языки

- Русский (ru) - язык по умолчанию
- English (en)

### Как это работает

1. В главном меню бота нажмите кнопку `🌐 Язык / Language`
2. Выберите нужный язык из предложенных вариантов
3. Язык сохраняется для вашего аккаунта
4. Все сообщения интерфейса отображаются на выбранном языке
5. API запросы к OpenWeather автоматически используют выбранный язык
6. Описания погоды и другие данные от API приходят на выбранном языке

### Добавление новых языков

Для добавления нового языка:
1. Добавьте код языка в `SUPPORTED_LANGUAGES` в `i18n.py`
2. Добавьте словарь переводов в `TRANSLATIONS` с ключом кода языка
3. Обновите функцию `handle_language_selection()` в `bot.py` для добавления новой кнопки
